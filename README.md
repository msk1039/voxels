# Voxels

Voxels is a local-first equation puzzle game. Players build target shapes on a
2D coordinate grid or in a 3D voxel world by writing safe mathematical
expressions.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

Campaign progress is stored in the browser. The project does not require a
database, account, or player-data service.
